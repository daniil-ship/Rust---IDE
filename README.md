## 🤔 What is Rust--?

**Rust--** is a simplified dialect of Rust, created for:

- 📚 Learning systems programming
- ⚡ Fast development without the complexity of full Rust
- 🔬 Experimenting with compilers and languages

Rust-- keeps the power of Rust while removing unnecessary complexity.

## 📦 Installation

### Requirements

- Operating system: Windows (soon / Linux / macOS)
- Nasm.exe (built-in)
- Llvm linker (built-in)
- rustc and cargo (built-in)
